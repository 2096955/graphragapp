Graphs for agent context: a field guide

Vector search finds passages that look similar. A graph finds facts that are connected. Tap any node to see what an agent can reach in one, two or three hops.

Covers Neo4j, FalkorDB, Neptune, Spanner Graph, PuppyGraph, Fabric graph, MongoDB Atlas, Cosmos DB and Kuzu. Prices and status as at 25 September 2026.

Lab 1: keyword retrieval against graph retrieval

Keyword search returns nodes whose text shares words with the question. Graph retrieval starts at the entities named in the question and follows relationships.

Lab 3: calibrated decisions with per-action thresholds

A simulation of the decision loop described in the paper. No model is called. Each case gets a stated confidence; the case is decided automatically if confidence clears that action's threshold, otherwise it is escalated at a cost of 1. Raise overconfidence to see what happens when stated probabilities stop matching reality.

One question, five dialects

The same question in each query language: which projects does John Doe lead, and who owns them?

MATCH (p:Person {name: 'John Doe'})-[:LEADS]->(proj:Project)<-[:OWNS]-(c:Company)
RETURN p.name, proj.name, c.name;

Run it on your laptop

Local options for the engines that have them. Neptune, Spanner Graph and Fabric graph are cloud-only.

Neo4j
docker run -p 7474:7474 -p 7687:7687 -e NEO4J_AUTH=neo4j/change-me neo4j:5

Browser UI on localhost:7474.

FalkorDB
docker run -p 6379:6379 -p 3000:3000 -it --rm falkordb/falkordb:latest

Browser UI on localhost:3000.

MongoDB
docker run -p 27017:27017 mongo:8

Local server; Atlas Vector Search needs Atlas or the Atlas CLI local deployment.

Kuzu
pip install kuzu==0.11.3

Final upstream release. Use a community fork for anything you will keep.

PuppyGraph
docker run -p 8081:8081 -p 8182:8182 -p 7687:7687 -d --name puppy --rm puppygraph/puppygraph:stable

Free Developer edition, single node. Check docs.puppygraph.com for the current image tag.

Sources and caveats

Prices are vendor list prices checked on 25 September 2026 and change often; confirm with each vendor's calculator before quoting to a client. Performance claims for PuppyGraph, FalkorDB and Jev are vendor-reported. Kuzu was archived in October 2025; the forks named here are community-maintained. Grades are the author's judgement against the stated weights.
